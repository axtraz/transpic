## Basic transformations

Convert an image to grayscale:

```bash
transpic --path photo.png --grayscale true
```

Resize an image to 1280x720:

```bash
transpic --path photo.png --resize 1280x720
```

Convert a PNG to WebP:

```bash
transpic --path photo.png --format webp
```

Rotate an image by 180 degrees:

```bash
transpic --path photo.png --rotate 180
```

## Combining multiple transformations

Resize, increase brightness, and export as JPEG in a single command:

```bash
transpic --path photo.png --resize 800x600 --brightness 15 --format jpeg
```

Blur, invert colors, and rotate the hue:

```bash
transpic --path photo.png --blur 3 --invert true --huerotate 45
```

## Batch processing

To process every image in a directory, loop over the files and call `transpic` once per file.

<Tabs items={['Bash', 'PowerShell']}>
  <Tab value="Bash">
    ```bash
    for file in ./images/*.png; do
      transpic --path "$file" --resize 1024x1024 --format webp
    done
    ```
  </Tab>
  <Tab value="PowerShell">
    ```powershell
    Get-ChildItem .\images\*.png | ForEach-Object {
      transpic --path $_.FullName --resize 1024x1024 --format webp
    }
    ```
  </Tab>
</Tabs>

<Callout type="info">
  Output files are written to the current working directory using the input file's name (with a new extension if `--format` changes it). Run the loop from a dedicated output folder if you don't want to overwrite your originals.
</Callout>
