## Introduction
Transpic is a powerful tool designed to help you manage your images with ease. Whether you're a developer, designer, or content creator, Transpic provides a seamless experience for handling your image assets.

## Installation
To get started with Transpic, you can install the command-line interface <span className='text-fd-muted-foreground text-sm'>(CLI)</span> globally using npm. This will allow you to access Transpic commands from anywhere in your terminal.

```npm
npm install -g transpic-cli
```

## Usage
Once you have the CLI installed, you can start using Transpic to manage your images. Here are some common commands to get you started:
- `transpic --help`: Display the help menu with all available commands.
- `transpic --path <directory> --format <format>`: Process images in the specified directory and convert them to the desired format.
- `transpic --blur <intensity>`: Apply a blur effect to your images with the specified intensity.
