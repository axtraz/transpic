## Overview

Transpic-cli is a fast, simple image manipulation CLI written in Rust. This page explains how it differs from the most popular tools in the same space.

---

## ImageMagick

ImageMagick is the industry standard for image manipulation. It has been around since 1990 and supports an enormous range of formats and operations. If you need advanced compositing, drawing, PDF handling, or hundreds of filters, ImageMagick is the right tool.

transpic-cli is not trying to replace ImageMagick. It covers the most common use cases with a dramatically simpler setup and a much faster execution time.

### Feature Table

| Feature | transpic-cli | ImageMagick |
|---|---|---|
| Install | `npm i -g transpic-cli` | System package or manual build |
| Binary size | ~5MB | ~30MB+ |
| Written in | Rust | C |
| Syntax | Simple | Complex |
| Conversion | ~10ms  ⚡ | ~40ms |
| Open source | ✅ | ✅ |
| No system dependencies | ✅ | ❌ |
| npm install | ✅ | ❌ |
| CI/CD friendly | ✅ | ⚠️ Setup required |
| Memory usage | Low | High |

transpic-cli is **~4x faster** than ImageMagick on a JPG → PNG conversion.

If you've ever copy-pasted an ImageMagick command from Stack Overflow without fully understanding it, transpic-cli is for you.

```bash
# ImageMagick
convert input.png -resize 800x600 -colorspace Gray output.png

# transpic-cli
transpic --path input.png --resize 800x600 --grayscale
```
